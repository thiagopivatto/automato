================================================================================
  ULTRON — LISTA COMPLETA DE COMANDOS
================================================================================
Gerado a partir do código (bot/comandos/*).
Prefixo padrão: !  (configurável pelo dono)
Ajuda no WhatsApp: !<comando> guia

LEGENDA — QUEM PODE
  • Qualquer usuário ........ membro comum / PV (se pvliberado)
  • Só em grupo ............. não funciona no privado
  • Admin do grupo .......... precisa ser admin do grupo
  • Bot admin ............... o bot precisa ser admin do grupo
  • Dono do grupo ........... só o criador/dono do grupo
  • Dono do bot ............. exclusivo do dono cadastrado

RESTRIÇÕES GERAIS
  • Limite diário / taxa de comandos podem estar ativos (dono)
  • Comandos podem ser bloqueados no grupo (!bcmd) ou global (!bcmdglobal)
  • Grupo mutado (!mutar): membros comuns não usam comandos
  • PV: comandos no privado só se !pvliberado estiver ligado
  • Usuário bloqueado pelo bot não usa comandos
  • APIs: .env (GEMINI, OPENROUTER, RAPIDAPI, ELEVENLABS, ACR, Deepgram, etc.)
  • Downloads YT/IG: yt-dlp no PATH (ou YTDLP_PATH / cookies)
