# Termux

1. Atualize pacotes e instale o Git:

```bash
pkg update -y && pkg upgrade -y && pkg install git -y
```

2. Clone o Ultron e entre na pasta do projeto.

3. Dependências do Termux (se existir o script):

```bash
sh termux_reqs.sh
```

4. Instale e inicie:

```bash
npm i
npm start
```
